# Reconstructed reports

The JSON reports of this one Top100 scan (GPT-5.1, T=0, pyjwt-2.10.1; no finding reached R) were lost after they were
imported; the run log next to this folder is the original. These three files were regenerated field by field from the
result database so that `scripts/build_dbs.py` rebuilds it exactly. They sit in a subfolder so that the log parsers,
which walk the scan folders, see the scan as it was on disk.
