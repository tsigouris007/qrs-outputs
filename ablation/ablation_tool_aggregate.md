# Per-Configuration Per-Tool Averages (per scan)

Average tool usage (calls, tokens, cost, execution time) per scan, broken down by agent (Query / Review / Sanity) and tool, for each of the 10 model/run configurations, plus the compact aggregate across all 1000 scans.

## Legend

Tool abbreviations:

| Abbrev. | Tool |
|---|---|
| `pp` | `package_profile` |
| `eq` | `execute_query` |
| `fq` | `fixup_query` |
| `fr` | `finalize_report` |
| `rsn` | reasoning (LLM decision/thinking budget, not tied to a tool call) |
| `ecs` | `extract_code_snippet` |
| `gs` | `grep_search` |
| `tf` | `trace_flow` |
| `sf` | `submit_finding` |
| `cr` | `complete_report` |
| `vf` | `verify_finding` (composite of two tools: a factual `search_cve` tool — which can be disabled — and a contextualized `verify_finding` tool) |

Agents: **Q** = Query, **R** = Review, **S** = Sanity.

Columns: `calls` = average tool calls per scan, `in_tok`/`out_tok`/`tot_tok` = average input/output/total tokens, `cost$` = average cost in USD, `exec_s` = average tool subprocess wall-clock execution time in seconds (in-process tools are sub-second).
