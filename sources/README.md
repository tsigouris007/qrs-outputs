# Package source files

Unmodified files from the public PyPI source distributions of the scanned package versions (each under its own
licence), limited to the files that two checks open: the 12 confirmed issues' files (`sast_recall.py` classifies SAST
alerts by enclosing function) and the files cited by the single agent's findings (`sa_analyze.py` checks that they exist).
Every other check works on the scan outputs alone.
